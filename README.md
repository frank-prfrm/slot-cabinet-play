# Slot Cabinet: play

The slot cabinet's games, built to play in a browser and to install on a
phone. This repo holds only the built site; it is published from the
cabinet's own (private) repo and replaced whole each time.

- **Play:** https://frank-prfrm.github.io/slot-cabinet-play/
- **How to install it and play:** https://frank-prfrm.github.io/slot-cabinet-play/help.html
